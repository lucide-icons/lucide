# Icon eligibility

Before designing a new icon or substantially redesigning an existing one, make sure the concept is suitable for Lucide.

## Excluded contributions

Lucide does not accept:

- Brand icons or logos. See our [brand logo statement](/brand-logo-statement) for the reasons behind this policy.
- Hate symbols or discriminatory or dehumanizing imagery.
- Religious imagery.
- War- or violence-related imagery.
- Political imagery.
- Sexually explicit or graphic imagery.
- Designs copied or traced from sources with unclear provenance or without permission compatible with [Lucide's license](/license). Giving credit alone does not grant permission to use a design.
- Duplicates without a meaningful distinction, including near-identical concepts and purely decorative variations.

## Check for existing icons

Before adding a new icon, search the [icon library (including Lab)](/icons/?library=lab) to make sure the icon does not already exist.
