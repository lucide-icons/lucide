# Lucide Solid

Implementation of the Lucide icon library for Solid 2 applications.

## Installation

```sh
pnpm add @lucide/solid
```

```sh
npm install @lucide/solid
```

```sh
yarn add @lucide/solid
```

```sh
bun add @lucide/solid
```

> `@lucide/solid` is only for Solid 2, for Solid 1 use the [`lucide-solid`](https://www.npmjs.com/package/lucide-solid) package. Solid 2 is still a release candidate.
