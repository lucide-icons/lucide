# Lucide

Implementation of the Lucide icon library for web applications.

## Installation

```sh
pnpm add lucide
```

```sh
npm install lucide
```

```sh
yarn add lucide
```

```sh
bun add lucide
```

### CDN

```html
<!-- Development version -->
<script src="https://unpkg.com/lucide@latest/dist/umd/lucide.js"></script>

<!-- Production version -->
<script src="https://unpkg.com/lucide@latest"></script>
```
